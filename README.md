# MIRROR: LAST EARTH — 마지막 지구인

> **현재 상태 (2026-10-25)** — 프롤로그부터 C8 엔딩과 결과지까지 전체 플레이 가능.
> 1장 마지막 네 자리 → 2장 마지막 12킬로그램 → 3장 지구의 마지막 창(발사 컷신) → 4장 189일째 → 5장 붉은 행성에 첫발 → 6장 제로돔 → 7장 얼음 아래의 물 → 8장 첫 번째 헌장 → 엔딩 4종 → 결과지(9탭).
> 구현 결정과 논리 점검 기록: `design/06_IMPLEMENTATION_DECISIONS.md`. 검증 결과: `docs/TEST_REPORT.md`.

2087년, 지구가 끝나는 날. 추첨으로 뽑힌 평범한 시민이 마지막 우주선의 네 자리를 정하고, 7개월을 날아 화성에 첫 공동체를 만드는 한국어 2D 픽셀아트 게임입니다. 플레이 중 '어떤 방식으로 일했는지'를 기록해, 마지막에 탐색적인 MBTI 스타일·빅파이브 경향을 보여 주는 것을 목표로 합니다(공식 심리검사 아님).

## 실행
```bash
npm install
npm run dev          # 개발 서버
npm run build        # dist/ 정적 사이트 (GitHub Pages용)
npm run build:single # dist-single/index.html 한 파일 (더블클릭 실행용)
npm run preview      # 빌드 결과 미리보기
npm run typecheck && npm run lint && npm test
npm run test:e2e     # e2e 모드로 빌드한 뒤 설치된 Google Chrome으로 Playwright E2E (테스트 훅 window.__mle은 이 빌드와 개발 서버에만 있다)
```

## GitHub에 올리고 Pages로 배포하기
1. GitHub에서 빈 저장소를 만든다.
2. 이 폴더에서:
```bash
git config user.name "이름"
git config user.email "메일"
git commit -m "MIRROR: LAST EARTH — C1~C8 전체 플레이"
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```
3. 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 `.github/workflows/deploy.yml`이 typecheck·lint·test·build 후 자동 배포한다.
