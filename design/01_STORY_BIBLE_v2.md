# STORY BIBLE v2 — MIRROR: LAST EARTH / 마지막 지구인

> v1 STORY_BIBLE을 대체한다. v1의 확정 설정은 전부 유지한다: 가상의 2087년 재난(행성 폭발 아님) / 아크-06 총 6석(담·플레이어 고정 + 후보 6명 중 4명) / 6C4=15조합 전부 같은 장면 수로 지원 / 죽음·유혈·잔혹 묘사 없음 / 4엔딩은 우열이 아님 / 누구를 태웠는지는 성격 점수와 무관.

## 0. 로그라인과 세 기둥

**로그라인 ―** 선택받은 사람이 선택하는 사람이 된다. 추첨으로 뽑힌 평범한 시민이 마지막 배의 네 자리를 정하고, 7개월 뒤 화성의 문 안쪽에서 똑같은 질문(누구를 들일 것인가)을 반대편에서 다시 마주한다.

- **기둥 1 · 저울** ― 장마다 하나의 트롤리형 딜레마(총 8개). 정답도 지배 전략도 없다. 되돌릴 수 없고, 벌하지 않고, 채점하지 않는다.
- **기둥 2 · 거울** ― 후반 4장이 전반 4장을 비춘다. 엔딩 직후 MIRROR가 '선택의 거울'(서사 회고)을 보여 준다. 평가 문구는 없다.
- **기둥 3 · 온기** ― 바깥 세계는 거대하고 무섭지만 사람들은 손바닥만큼 귀엽다. 장마다 웃음 1회 이상 + 조용한 인간적 장면 1회 이상.

**긴장 곡선(1~5)** 프롤로그 4 → C1 5 → C2 3 → C3 5 → C4 2→4(반전) → C5 4 → C6 5 → C7 3 → C8 2→4→1(붉은 새벽)

## 2. 세 개의 미스터리 실 (복선 → 회수)

**실 A · 담의 침묵**
- C1 복선: 담의 손목에 '04'가 새겨진 낡은 팔찌. 물어보면(선택) '행운 번호야.'
- C3 복선: 상승 직후 담이 '아크-04 최종 항로 로그'를 1초 열었다 닫는다(HUD 구석, 조사 가능).
- C4 회수: 구조 신호 속 목소리 ― 담희, 담의 여동생이자 아크-04 정비사. 담: '이 결정에서 난 빠질게. 지금 내 판단은 못 믿겠어.'
- C8 재회수: 아크-04의 자동 요청. 담이 처음으로 묻는다. '...내 의견, 말해도 될까?'

**실 B · MIRROR가 16년 동안 지킨 것**
- C3: 상승 직후 수신. 'MIRROR입니다. 환영합니다, 정착민 0명. 정정. 6명.'

- C5: 착륙 안내가 16년 전 지형 기준이다. 첫 대면.
- C6 회수: 2년간의 모래폭풍 동안 MIRROR는 종자 저장고와 지구 기록 서버를 지키느라 산소 모듈 정비를 미뤘다. '사람이 올 거라는 확신은... 없었어요.'
- C7: 일꾼-3 ― MIRROR가 4년째 심박 신호만 듣고 있는 옛 건설 로봇.
- C8: '저는 거울이에요. 여러분이 한 일만 비출 수 있어요. 여러분이 누구인지는 몰라요.' → 결과 화면 전환. (행동 분석을 이야기 안으로 정직하게 끌어오는 장치. 동의는 이야기 밖, 플레이 전에 이미 받았다.)

**실 C · 남겨진 두 사람의 부탁**
- C1 명단 잠금 직후, 미선발 2명이 각자 물건 하나와 한마디를 건넨다(유산 아이템).
- C2 유산 아이템이 12kg 후보 목록에 들어온다. 가져갈지는 자유.
- C4 늦게 도착한 지구 영상 끝에 미선발자 1명의 음성 편지가 붙어 있다(하린 미선발이면 하린 우선).
- C8 회상 카드 2장. 가져간 유산 아이템은 돔 어딘가에 놓여 있다. 그들의 운명은 끝까지 알려 주지 않는다.

## 4. 8개의 저울 ― 딜레마 설계 규칙

1. 장마다 다른 가치 충돌을 다룬다(아래 표). 같은 충돌을 반복하지 않는다.
2. 모든 선택지는 최소 1개의 '가치 통화'(자원 / 관계 / 기억 / 타인의 위험 / 미래의 여유)로 값을 치른다. 어떤 선택지도 모든 통화에서 다른 선택지를 이기지 않는다(자동 테스트 dilemmaBalance).
3. 모든 선택지에 지지하는 목소리 1명 이상, 우려하는 목소리 1명 이상(승선자 기준 데이터 해석, 없으면 담·녹녹이·보람·MIRROR).
4. 중반 반전: 결정 직전에 판을 흔드는 정보가 하나 등장한다.
5. 되돌릴 수 없다. 대신 후속 장에서 '메아리'로 돌아온다.
6. 타인의 운명(보람, 아크-04, 두고 온 일꾼-3)은 끝까지 확정하지 않는다. 결과가 선악 판정처럼 보이지 않게.

## 7. 톤과 금지
