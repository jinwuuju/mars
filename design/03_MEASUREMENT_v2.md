# MEASUREMENT v2 — 행동 관찰 설계 · 채점 · 정밀도 · 검증

> v1 CODEX_MASTER_PROMPT §5와 BEHAVIOR_MATRIX v1을 대체한다. SCIENCE_AND_ETHICS가 최우선이다.

## 0. '정밀함'에 대한 정직한 정의
- 할 수 있는 것: 30분 동안 한 사람이 서로 다른 8개 상황에서 반복해서 보인 '일하는 방식'의 경향을, 근거와 불확실성까지 함께 보여 주는 것.
- 할 수 없는 것: 임상·채용·공식 성격검사 수준의 진단, 무의식의 객관 측정, 정식 MBTI 유형 판정.
- 예상 신뢰도(가정치, 미검증): 차원당 근거 약 8개, 행동 문항 간 평균 상관을 0.15~0.25로 가정하면 Spearman-Brown 기준 약 0.6~0.7. 개인 결과는 '방향과 경향' 수준으로만 해석해야 한다.
- 그래서 v2는 세 방향으로 정밀도를 올린다.
  1. 잡음을 줄이는 구조 ― 대칭 포크, 측정 중립성, 조작 비용 등가, 표시 순서 역균형, 딜레마 분리.
  2. 불확실성을 숨기지 않는 출력 ― 범위(LOCO), 방향 일관성, 근거 강도, 품질 경고.
  3. 나중에 실제로 검증할 수 있는 경로 ― 합성 회수 시뮬레이션, 선택형 자기보고 비교, 파일럿 계획.

## 1. 측정하지 않는 것 (v1 금지 + v2 추가)
누구를 태웠는지·제외했는지, 하린 관계, 권고안 수용 여부, 유산 수용, 짐 선택, 8개 저울 전부, 지구 영상 처리, 엔딩 대답, 헌장 정책·결정 방식, 정착지 이름, 미니게임 성공·속도·실수·힌트 사용, 반응 시간, 대사 스킵, 지구 조각 수집, 케미 앨범, 접근성 설정·입력 방식, 위험 감수, 감정 반응. Big Five N은 v1 내내 '판단 자료 부족'.

## 2. 측정 원칙 12
- P1 측정 중립성 ― 채점 행위의 양쪽 선택은 자원·플래그·엔딩·대사 보상·수집에 영향 0. NPC 반응 온도 동일.
- P2 대칭 관찰 ― 양 극을 똑같이 관찰할 수 있는 행위로만 채점한다. 무응답·미행동은 반대 극이 아니라 null.
- P3 비용 등가 ― 포크 양쪽은 클릭 수·이동 거리·이후 단계 수가 ±10% 이내.
- P4 순서 역균형 ― 포크 선택지의 화면 위치는 runSeed로 회전하고, 위치를 이벤트에 기록한다.
- P5 딜레마 분리 ― 저울 화면과 그 확정 모달에는 채점 기회가 없다. 측정은 운영·문제 해결 구간에서만.
- P6 단일 확정 ― 기회마다 창(window)이 닫힐 때 1회 확정. 새로고침·재진입·중복 클릭으로 재확정 불가.
- P7 독립성 ― 한 이벤트는 한 기회에만 귀속. 한 기회에서 두 차원을 뽑을 때는 서로 다른 행위를 쓰고 결과 화면에 공개한다.
- P8 학습 효과 통제 ― 프롤로그 튜토리얼에서 모든 UI 유형을 1회 체험(비채점). C1은 첫 노출 + 딜레마 근접 때문에 가중치 0.5.
- P9 보상 분리 ― 채점 기회는 수집·업적·도감·장면 해금과 연결하지 않는다.
- P10 편성 무관 ― 포크 선택지 구성은 crewIds·inventory와 무관하다. 바뀌는 것은 말하는 얼굴뿐. 편성 때문에 생기는 unavailable 목표 0건.
- P11 접근성 무관 ― 키보드·탭·드래그 어느 방식이든 같은 이벤트.
- P12 사전 등록 ― 행위·가중치·방향은 src/analytics/scoring.ts에 고정하고 결과 화면에서 규칙표를 공개한다.

## 3. 관찰 기회 구조
장마다 6개: O01 INFO / O02 VARIANT / O03 ORDER / O04 SOCIAL / O05 PERSPECTIVE (채점 5) + O06 STORY(비채점). 총 48 = 채점 40 + 스토리 8. (v1 ID 체계 유지, 장마다 패밀리 순서를 통일)

퀴즈처럼 보이지 않게 세 가지 형태로 세계 안에 녹인다.
- 포크(Fork): 녹녹이·MIRROR·동료가 '방식'을 묻는 말풍선 2버튼, 또는 세계 속 두 사물. 두 버튼은 같은 크기·같은 애니메이션.
- 2탭 패널: 정보 패널을 열면 두 탭 중 하나를 먼저 골라야 내용이 보인다. 결정에 필요한 정보는 이미 본 화면에 있다.
- 대칭 핫스팟: 맵 위 '함께'와 '혼자' 지점이 같은 거리에 짝으로 존재.

| 패밀리 | 차원 | + 극 행위 (가중치) | − 극 행위 (가중치) | 값 |
|---|---|---|---|---|
| INFO | SN (+N / −S) | 패널마다 처음 고른 탭이 '추세·가능성·가설'(1, 극당 상한 3) | 패널마다 처음 고른 탭이 '실측·기록·원자료'(1, 극당 상한 3) | 연속 |
| VARIANT | O | [새 방식 / 직접 구성 / 여러 안 비교](1) | [표준 / 기본안 / 템플릿](1) | 이진 |
| ORDER-C | C | [수동 재점검 / 직접 재확인](1) | [자동 확인 수용 후 진행](1) | 이진 |
| ORDER-JP | JP (+J / −P) | [계획·순서표 먼저](1) | [하면서 정하기](1) | 이진 |
| SOCIAL | E · EI (+E / −I) | 포크 [함께 / 묻기 / 교신](2) + 함께 핫스팟(1, 상한 2) | 포크 [혼자 / 집중 / 개인 기록](2) + 혼자 핫스팟(1, 상한 2) | 연속 |
| PERSPECTIVE-A | A | [요청대로 조정](1) | [원안 유지하고 이유 설명](1) | 이진 |
| PERSPECTIVE-TF | TF (+F / −T) | '사람·요청 메모' 패널 먼저(1) | '수치·부하' 패널 먼저(1) | 연속 |

기술 통계(표시만, 채점 안 함): 미리보기 횟수, 자발 추가 점검 횟수, 힌트 사용, 수집 수. 한쪽 극에만 존재하는 행위는 P2에 따라 점수에서 뺀다.

## 4. 특징 추출
- f(opportunity, dim) = (W+ − W−) / (W+ + W−), 범위 [-1, 1].
- 행위가 하나도 없으면 null(skipped). 기회가 제시되지 않았으면 unavailable. 둘 다 평균에서 제외하고 반대 성향으로 처리하지 않는다.
- 상한 초과 행위는 기록만 하고 가중치 0.
- 확정 시점: 기회의 창(해당 미니게임·구간)이 닫힐 때. 이후 같은 opportunityId 이벤트는 무시하고 중복 카운터만 올린다.
- 이벤트 형식: { id, chapter, opportunityId, family, actionType: fork | tab | hotspot, pole: + | -, weight, displayPosition, optionSetId, pressureTag: H | L, timestamp }. 승선자·소지품 정보는 담지 않는다.

## 5. 집계
1. 장 점수: 각 차원에서 그 장 기회의 f(장당 1개). C1 가중치 0.5, 나머지 1.
2. 차원 점수 m = 장 점수들의 가중 평균(결측 제외).
3. 표시 임계: 유효 장 ≥4 (차원마다 장당 기회가 1개라 예전 표기 '유효 장 ≥3 그리고 유효 기회 ≥4'와 같은 기준. 코드: MIN_CHAPTERS = 4). 미달이면 숫자 없이 '근거 부족'.
4. 지수 = round(50 + 50 × m). 이름은 '게임 속 행동 지수'. 백분위·확률·순위가 아니며 사용자 간 비교 문구 금지.
5. 80% 범위: 장별 값의 가중 표준오차 × t(80%) (표준편차 하한 0.35) → 결과지의 지수 범위 막대. 시뮬레이션 포함률 약 77%, 평균 폭 ±18~25점. LOCO(한 장씩 빼고 다시 계산한 최소~최대)는 실제 성향을 30~40%만 포함해서 범위 표시에 쓰지 않고, 확실도(부호 안정성) 판단에만 쓴다.
6. 방향 일관성: 유효 장 가운데 m과 부호가 같은 장의 비율.
7. 근거 강도: ★★★ 유효 7~8장 + 일관성 ≥0.75 + LOCO 폭 ≤20 / ★★ 유효 5~6장 또는 위 조건 일부 / ★ 그 외.
8. 4축 글자와 확실도 (2026-10-25 시뮬레이션 반영): 임계 미달 → ? / |m| < 0.10 → X(거의 동률) / 그 외 가까운 쪽 글자 + 확실도 1(약함) / |m| ≥ 0.25이고 LOCO 구간 전체가 같은 부호 → 확실도 2(보통) / 확실도 2 + 유효 장 6개 이상 + 장별 부호 검정 p ≤ 0.10 → 확실도 3(강함). 처음 규칙(|m| ≥ 0.25 + LOCO)으로는 무작위로 누르는 사람도 축마다 약 70% 확률로 '확정' 글자를 받는다는 것을 시뮬레이션으로 발견해 바꿨다. 같은 패널에서 두 번째로 연 탭은 근거로만 남기고 가중치 0이다(처음 규칙의 0.5 가중치는 두 탭을 모두 여는 사람의 점수를 0으로 만드는 문제가 있었다).
9. Big Five N: 항상 '판단 자료 부족 ― 짧은 게임과 위기 상황만으로는 이 영역을 추정하지 않아요.'
10. 공유 근거 공개: EI는 E와 같은 SOCIAL 근거를 쓴다. JP와 C는 같은 ORDER 기회의 서로 다른 포크를 쓴다. TF와 A는 같은 PERSPECTIVE 기회의 서로 다른 행위를 쓴다. 결과 화면에 그대로 적는다.

## 6. 상황별 행동 차이 (if-then 프로파일)
압박 태그를 균형 배치했다: H = C1, C3, C5, C6 / L = C2, C4, C7, C8. 한 차원에서 H·L 양쪽 유효 장이 각각 3개 이상이면 두 평균을 나란히 보여 준다. |차이| ≥ 0.5일 때만 '상황에 따라 달랐어요', 아니면 '비슷했어요'. 이 차이로 N이나 스트레스 취약성을 추정하지 않는다고 명시한다.

## 7. 데이터 품질 게이트
- 위치 편향: 포크 20개 이상 중 같은 화면 위치 선택 비율 ≥0.85 → '한쪽 버튼을 주로 누른 패턴' 경고, 4축 문자 숨김, 지수 회색 표시. (2026-10-25 2차 점검에서 구현: 표지·MBTI 상세의 글자와 유형, 이미지 저장, 유형 프로필·궁합·닮은 인물 탭을 숨긴다. 그 전에는 경고 문구만 있었다.)
- 관찰률: 채점 기회 40개 중 유효 20개 미만 → 결과 보류, 플레이 통계만.
- 분석 끄기: 이벤트를 아예 만들지 않는다. 결과 없음.
- 품질 판정에 반응 시간은 쓰지 않는다.

## 8. 결과 화면
- 배경: 돔 창문에 비친 플레이어 캐릭터.
- 빅파이브 5카드: 지수(또는 근거 부족), 80% 범위 막대, 근거 강도, 근거 사례 2~3개(실제 저장 이벤트만. 예: 'C3 진단 때 〈추세·가설〉 탭을 먼저 열었어요'), 반대 방향 근거 1~2개, [그때 무슨 일이 있었나] 장면 요약.
- MBTI 4축(EI · SN · TF · JP): 글자 / X / ?, 막대, 근거. 확실도 표기는 3 '뚜렷함' / 2 '경향' / 1 '약한 경향'이며, 무작위로 눌러도 '경향'이 40~55% 나온다는 시뮬레이션 결과를 함께 고지한다. TF는 '결정할 때 먼저 찾아본 정보의 종류'로 설명하고 감정 대 논리의 우열로 읽히지 않게 쓴다.
- 상황별 행동 차이(조건 충족 시), 규칙표 공개, 한계 고지, 품질 경고.
- 플레이 통계(비채점): 지구 조각, 케미 앨범, 본 장면 수.
- 버튼: [이미지 저장] [다시하기] [기록 삭제] [선택형 자기보고 비교](D3 결정 시).
- 금지 문구: '진짜 당신은', '정확도 n%', '상위 n%', '무의식', '당신의 MBTI는'. 권장 문구: '이번 플레이에서 보인 경향', '근거 n개', '범위'.

## 9. 명칭
(2026-10-25 갱신) UI에서 'MBTI'를 그대로 쓴다. 단, 결과 첫 화면과 푸터에 '공식 MBTI® 검사가 아니라 게임 속 행동으로 추정한 비공식 결과'라고 명시한다. 글자마다 확실도(점 1~3개)를 함께 보여 주고, X나 ?인 글자는 '두 유형 사이'로 표시한다(05_RESULTS_AND_POSTGAME_v2 참조). Big Five는 '빅파이브 5영역'.

## 10. 합성 플레이어 회수 시뮬레이션 (개발 중 정밀도 점검)
- 목적: 채점 알고리즘이 이상적인 조건에서 성향을 얼마나 되살리는지 측정. 실제 타당도가 아니다.
- 합성 플레이어: 차원별 성향 q ∈ [0.1, 0.9]를 무작위 배정, 포크에서 + 극을 q 확률로 선택, 탭·핫스팟도 같은 규칙. 위치 편향형·무작위형 플레이어도 섞는다.
- 2,000명 × 전체 플레이 → 차원별 corr(q, 지수), LOCO 범위의 q 포함률, 4축 문자 오분류율, 위치 편향 탐지율을 TEST_REPORT에 기록.
- 결과 화면 한계 고지에는 '이상적 조건에서의 알고리즘 회수율'로만 인용한다.
- 2026-10-25 실행 결과: tests/measurementSim.test.ts, 표는 docs/simulation/measurement.md.

## 11. 선택형 자기보고 비교 (D3 · 결정 대기)
결과 화면 뒤 선택 메뉴. 공개 도메인 IPIP 문항 기반 20문항(Mini-IPIP 구조)으로 빅파이브 자기보고를 받아 행동 지수와 나란히 보여 준다. 합산하지 않는다. 한국어 번역은 비검증이라고 표기. 로컬 저장만. 목적은 '내가 말한 나'와 '게임에서 행동한 나'의 비교.

## 12. 검증 로드맵
- 단계 0: 합성 회수 시뮬레이션(개발 중).
- 단계 1: 내부 플레이테스트 n≈30 ― 포크마다 선택 비율이 30~70%인지(한쪽 쏠림 포크는 문구·연출 수정), 위치 편향, 비용 등가 체감.
- 단계 2: 동의 기반 파일럿 n≥200 ― 사용자가 자발적으로 내보낸 익명 파일과 검증된 빅파이브 척도를 비교해 수렴 타당도, 문항-총점 상관, 가중치 재추정.
- 단계 3: 재검사 신뢰도(같은 사람이 다른 편성·다른 저울로 2회).
- 단계 2 전까지 모든 결과는 '탐색적'으로 표기한다.

## 13. 개인정보
분석 동의는 플레이 전, 언제든 끄기 가능, 끄면 결과 없음. 저장은 이 기기 브라우저만. 서버 전송 없음. 기록 삭제 버튼. 내보내기는 이벤트·점수만(이름·외형·정착지 이름 제외), runId는 무작위.
