# 과학·측정·윤리 가드레일

## A. 실제 화성 환경과 미래 SF 설정을 구분
- **현재 알려진 화성:** 중력 지구 대비 약 38%; 평균 대기는 주로 이산화탄소이며 매우 희박함. 현재 야외에서 맨몸 호흡 불가능. 표면은 추위·방사선·먼지에 노출됨. 일주기는 약 24시간 37분. 지하 수빙 존재 가능. (NASA Mars Facts; NASA NSSDC Mars Fact Sheet)
- **지구~화성 비행:** 현대 일반적인 저에너지 전이 구간은 약 6~9개월, 유리한 발사창 대략 26개월 주기. 그래서 C4 `항해 189일째`와 C5 `7개월 안팎 착륙`은 양립 가능. 정확한 여행일수는 궤도와 기술에 따라 달라짐. (NASA Mars Mission Timeline; NASA Red Planet Dispatch)
- **공기·물:** 화성 대기의 CO₂로부터 산소를 생산하는 MOXIE 기술은 실증됐지만, 미래 거주용 상업적 대규모 정착 기지는 아직 실현된 사실이 아님. CO₂ 제거·산소 제조·기압 관리 별도 기능. 수빙을 발견하더라도 추출·처리·분석을 거쳐야 함. (NASA MOXIE)
- **가상 설정:** 2087년 혜성 파편 재난, 지구 장기 거주 불가능, 16년간 자동 건설된 화성의 `제로돔`, 성인 6명 수용 우주선 `아크-06`, 안정적인 7개월 항해, 특정 미니게임의 장비 효율과 수치. 위 항목들은 실제 미래 예측이나 NASA의 공식 임무 계획이 아니라 게임 내 창작물임을 인트로/도감 등에서 분명히 표기.
- 화성이 지구보다 살기 좋은 대안이라거나, 현재 인류를 대규모로 화성에 이주시킬 수 있다는 주장 금지. 환경적으로 지구 보전의 가치가 크다는 관점을 NPC를 통해 표현할 것.
- 지구가 '폭발'한다는 그림과 설명 대신, 지표면의 심각한 재난과 문명 붕괴로 묘사한다. 우주에서 보이는 검붉은 지구는 **극적으로 표현한 미래 SF 연출**이라고 고지.

## B. 심리측정과 윤리
- 이 게임은 **탐색형 행동 분석 게임**, 임상검사·공식 MBTI·고용평가용 도구 아님.
- 자기보고 편향을 줄이려는 시도라도 게임 조작 숙련, 장르 경험, 상황 맥락, 접근성, 캐릭터 애착, 문화적 가치가 영향을 준다. 스스로 '무의식'을 객관 측정한다고 단정 금지.
- **절대 금지:** 친족 하린 탑승 여부→우호성/이기성 점수, 전문가 탈락→낮은 성실성, 유품 선택→개방성, 재난 대응속도→신경성, 용감한 외부탐사→외향성, 누군가를 포기한 결정→T/F, 위기 때 울거나 멈칫함→N. 게임 상황에서의 도덕 판단·신변 위험 선택은 성격 점수로 사용하지 않는다.
- 48 기회 가운데 각 장의 마지막 하나는 이야기 결과 확인 `STORY`; 40개만 관찰 가능한 과정 feature 후보이며, 실제로 관찰되지 않으면 제외. 미선발 NPC가 없어도 적어도 하나의 기능적으로 동등한 협의/정보 탐색 경로를 제공하여 측정 기회의 불평등을 줄인다.
- Big Five O/C/E/A와 유사 MBTI 축은 과학적 검증 전에는 **게임 내 행동 경향 지수**, 조건부로만 출력. Big Five N은 1차에서 **판단 자료 부족**으로 고정하고 숫자 출력 금지. 빅파이브 5영역은 화면에서 유지.
- 임계: 영역/축별 최소 3개 독립 챕터 + 서로 다른 관찰 기회 4개가 충족될 때만 계산. `unavailable`/`skipped`/`observed` 구분, 무응답을 반대 성향으로 자동 처리하지 않는다. 동점/근접한 MBTI 축은 X, 자료 부족은 ?를 표시한다. 단일 사건으로 유형 판정하지 않는다.
- 점수는 차원별 사전 명세한 독립적 event feature에 따라 결정. 단순 클릭 횟수/시간/사망 회피/퍼즐 성능은 성격에 연결하지 않는다. 캐릭터 보너스/보유 장비에 따른 선택 기회 차이는 통제.
- 이용자에게 시작 전 '행동 기록으로 탐색적인 결과를 제공하며, 저장은 이 기기의 브라우저에만 한다'고 안내. 개인정보·실명 불필요, 로컬 데이터 전용. 분석 끄기 모드로 플레이할 수도 있게 하고 이 경우 결과를 만들지 않는다. 기록 삭제. 데이터 내보내기 시 개인 식별 정보 포함 방지.
- 강렬한 지구 종말 연출을 고려해 시작 화면에 가벼운 내용 안내(재난·생존자 선별·가족과의 이별 포함), 연출 강도 조절 옵션, 모션 감소, 음량 OFF 기본, 텍스트 대체, 프롤로그 스킵을 지원한다. 선택 때문에 플레이어를 비난하지 않는다.
