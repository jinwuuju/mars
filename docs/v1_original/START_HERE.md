# MIRROR: LAST EARTH — Codex 시작 안내

1. 새 Codex 프로젝트 폴더를 만든다(예: `mirror-last-earth`).
2. 이 압축파일의 **내용물 전체**(`AGENTS.md`, `CODEX_MASTER_PROMPT.md`, `STORY_BIBLE.md`, `BEHAVIOR_MATRIX.csv`, `SCIENCE_AND_ETHICS.md`)를 프로젝트 최상위 경로에 복사한다.
3. 기존 축제 프로젝트에 이어 개발하는 경우, 기획을 덮어쓰는 것이 아니라 **완전히 새로운 서사와 데이터 구조**로 이행한다. 옛 세이브는 버전 분리하며 손상 없이 안내해라.
4. 다음 지시문을 Codex에 보낸다.

```text
프로젝트 루트의 AGENTS.md, CODEX_MASTER_PROMPT.md, STORY_BIBLE.md, BEHAVIOR_MATRIX.csv, SCIENCE_AND_ETHICS.md를 모두 완독하라. 이 파일들이 유일한 개발 기준이다. 2087년 지구 종말로 시작해 실제로 네 개의 탑승자를 선택하고 화성에 정착하는, 한국어 2D 픽셀아트 게임 MIRROR: LAST EARTH를 구현하라. 설명용 웹사이트나 카드형 설문이 아니라 실제 움직이는 캐릭터, 상호작용 지도, 승선 명단 인터페이스, 자원 퍼즐, 수리·착륙·채굴 미니게임을 갖추어라. 귀엽고 풍성한 오리지널 캐릭터/그래픽의 품질을 우선한다. 8개 챕터 전체가 실행 가능하고, 48개 관찰 기회가 접근 가능하며, 행동 증거 기반 탐색적 성격 결과가 재현 가능하도록 하라. 명세의 개발 순서와 E2E 조건에 따라 코드 작성·실행·테스트·수정을 끝내고 실제 수행한 결과와 미완료 항목을 정직하게 보고하라.
```

## 테스트할 핵심 시나리오
- 친동생 하린을 포함해 4명 선택한 루트 / 제외한 루트 모두 이어지는가?
- 의료진 서진을 제외해도 대체 경로가 있어 엔딩까지 플레이 가능한가?
- 누구를 태웠든 선택된 4명만 실제 선내·화성 기지에 나타나는가?
- 지구 탑승자 선택 자체가 성격 점수에 반영되지 않는가?
- 8개 챕터의 48 기회가 등장하고 중복 채점되지 않는가?
- 사건의 심각성을 희화화하지 않으면서도 캐릭터가 귀엽고 UI 조작이 재미있는가?
- 오프라인 동작, 저장·재개, 모바일 조작, 키보드, 결과 근거 링크가 작동하는가?

이 패키지는 구현 지시서와 기획 자료이며, 실행 가능한 게임 코드가 아니다.
